## 4. Component Implementation

### 4.1 `src/domain/multas.js` (A)

**Responsibility:** UC-008..010 · **Refs:** INV-FIN-001..003

```js
export function calcularMulta(hasta, devueltaEl, tarifa) // → { dias, importe } | null
export function tieneMultaPendiente(multas, correo)
export function marcarMultaPagada({ repo }, actor, { multaId })
export function listarMultas({ repo }, actor)
```

**Notes:**
- Sin retraso (`devueltaEl <= hasta`) no hay multa.
- La multa solo se crea al pasar a `Devuelta`; repetir la devolución es `O_ALREADY_RETURNED` y no escribe.
- Si falla la escritura de la multa, la devolución se deshace (AC-008-05).

### 4.2 `src/domain/reservas.js` (A)

`devolverReserva` llama a `calcularMulta` dentro de la transacción; `crearReserva` consulta `tieneMultaPendiente` antes del duplicado.
